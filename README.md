# portf

Portfolio for Wilson Anggriawan, live at [port.wilsb.me](https://port.wilsb.me).

Next.js 16 App Router, Tailwind v4, Motion. All copy, projects, uses and tracks are typed data under `content/`; the GitHub section reads `content/github.ts` and never calls the API at runtime.

```bash
pnpm install
pnpm dev
```

Deployed on Vercel from `main`.
